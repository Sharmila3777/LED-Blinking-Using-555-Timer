# LED Blinking Using 555 Timer IC

## Project Overview
This project demonstrates a simple LED blinking circuit using the NE555 Timer IC in Astable Mode.

## Components Used
- NE555 Timer IC
- LED
- 220Ω Resistor
- 10kΩ Resistor
- 100kΩ Resistor
- 10µF Capacitor
- Breadboard
- Jumper Wires
- 9V Battery

## Working Principle
The 555 Timer is configured in Astable Mode to generate a continuous square wave. The output alternates between HIGH and LOW, causing the LED to blink repeatedly.

## Learning Outcomes
- Understanding the 555 Timer IC
- Breadboard circuit building
- Component identification
- Practical electronics fundamentals
